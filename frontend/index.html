Setup Notice

YouTube API Key Required for Live Queries

LoopLens is strictly connected to authentic YouTube Data API v3 and never invents or fakes results. To fetch live video data and comments, set your API key in the server's .env file.

1 Get a free API key from the Google Cloud Console.
2 Open the .env file in the project folder and set YOUTUBE_API_KEY=your_key_here.
3 Restart or refresh the page. Your key stays 100% server-side and is never exposed in browser code.

Protecting Viewer Time

Authentic Evidence Only

LoopLens connects directly to YouTube's public API. We never fabricate comments or pretend to perform pixel-level verification where only community reports exist.

🔒

Zero API Key Leakage

All YouTube Data API v3 communication happens strictly on the backend server. Your credentials and environment variables are never transmitted to client browsers.

Computer-Vision Prototype

Visual repeated-footage detection operates locally on user-provided clips via perceptual difference hashing. It filters static scenes to prevent false positives and does not access YouTube streams.
